# Journal

Decisiones y por qué. Solo se añade, las entradas más nuevas arriba. Una decisión recibe un nombre estable tras el signo ⚖️ y tres campos: decidido, rechazado, palabras del dueño. El razonamiento que no es una decisión entra como una entrada normal con fecha y autor.

## [AAAA-MM-DD HH:MM] · [agente o persona] · ⚖️ adopt-spec-driven-company · La verdad vive en docs, los agentes ejecutan, el estado se ve

**Decidido.** Este proyecto funciona como una Spec-Driven Company. Las reglas viven en `AGENTS.md`. La verdad vive en `docs/`: este journal para las decisiones, `README.md` para el resumen de una página, un archivo por zona para cómo funcionan las cosas. Los agentes trabajan en worktrees, escriben la especificación antes que el código, ejecutan la comprobación antes de cada commit y se detienen ante el dinero, las claves, los datos personales y todo lo que se publique fuera.

**Rechazado.** Guardar la verdad en el historial del chat y en la cabeza de la gente. No sobrevive a una nueva sesión del agente ni a una persona nueva.
