# Stacks

A stack is a spec in words. It says what the app is made of and what "up" means; it does not pin versions. The agent installs what is current on the day it runs.

To use one: paste the stack prompt from the [root README](../../README.md); it saves the stack file as `docs/stack.md` in your project.

To add one: a pull request with one file in this folder, the same shape as [next-convex.md](next-convex.md): what is in it, what the agent must build, where it must stop, the done criterion.
